Project: Will AI be Readmitted?
Project overview: AI-assisted hospital readmission assessment made

Features:
- Interactive interface, checking for readmission through user inputs.
- BMI, Comorbidity, and Diabetes are the key factors.
- Real-time output.

Program stack:
- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- Machine Learning Dependencies: scikit-learn, XGBoost
- Machine Learning Algorithms: Random Forest, Logistic Regression, Decision Tree, and XGBClassifier
- Deployment: GitHub + Render/Railway/Heroku

Repository Structure:
- notebooks/ Actual whole notebook with Flask deployment
- models/ Trained models
- src/ Python source scripts
- data/ Data dictionary and dataset with source
- Readme.md
